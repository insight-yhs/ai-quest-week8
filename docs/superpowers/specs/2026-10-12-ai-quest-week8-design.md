## 2. 구조

```
index.html      학생용 게임 (단일 페이지, 화면 전환)
board.html      교수자용 순위판 (?class=A|B|T, 5초 폴링)
css/style.css
js/content.js   문제·해설·열쇠 코드 (교수자가 직접 수정하는 유일한 파일)
js/logic.js     순수 함수: 채점, 순서 판정, 코드 확인, 순위 정렬 (node 테스트 대상)
js/game.js      화면 전환·상태 저장(localStorage)·점수 전송
js/board.js     순위판 렌더링
js/config.js    Apps Script 웹 앱 URL
apps-script/Code.gs  점수 저장(doPost)·순위 조회(doGet)
tests/logic.test.mjs
```

- 빌드 도구 없음. ES 모듈 + 정적 파일. GitHub Pages `insight-yhs/ai-quest-week8`.
- 점수 흐름: 스테이지 완료 → `POST {cls,nick,pid,stage,score}` (text/plain, 프리플라이트 회피) → 시트 `scores`에 pid 기준 upsert(LockService) → `GET ?cls=A` → `[{nick,total,stages}]`.
- 서버 실패 시: 게임 진행·점수 표시는 그대로, 전송은 다음 스테이지 완료 때 재시도. 순위판은 "연결 대기 중" 표시.
- 상태 저장: localStorage(pid, 반, 닉네임, 열린 스테이지, 스테이지별 점수). 접근 실패 시 메모리로 동작.
- 개인정보: 닉네임(최대 10자)만 수집, 학번 없음. 부적절한 닉네임은 교수자가 시트에서 행 삭제.
- 반 선택: A반 · B반 · 연습(T). 리허설은 T로.

## 3. 게임 규칙

- 정답 100점 + 속도 보너스 `round(50 × max(0, 1 − 걸린초/20))` (0~50). 오답 0점, 감점 없음.
- 순서 맞추기: 제자리 카드 하나당 60점(5장 = 300점), 속도 보너스 없음.
- 문제마다 정답 공개 후 한두 문장 해설을 보여 주고 [다음]으로 넘어간다.
- 스테이지 재도전 없음(첫 점수만 순위에 반영).
- 열쇠 코드: 대소문자 무시, 공백 무시. 1 `MIND` · 2 `TIME` · 3 `WORD` · 4 `FACT`. 연습 문제는 코드 없음.
- 순위판: 반별 총점 상위 10명, 참여 인원, 스테이지별 완료 인원. 동점은 먼저 도달한 순.

## 4. 문제 (쉬운 버전 초안)

판단 기준(1스테이지): **정해진 규칙대로만 움직이면 AI 아님, 데이터에서 배워 스스로 판단하면 AI.**

### 연습
- 오늘 수업 주제는? → 인공지능

### 스테이지 1. AI일까, 아닐까? (10문항, 각 2지선다)
| 기술 | 정답 | 해설 |
|---|---|---|
| 계산기 | 아님 | 정해진 계산 규칙대로만 계산한다 |
| 유튜브 영상 추천 | AI | 내 시청 기록에서 취향을 배워 고른다 |
| 얼굴 인식 잠금 해제 | AI | 많은 얼굴 사진으로 배운 특징으로 나를 알아본다 |
| 엘리베이터 층 버튼 | 아님 | 누른 층으로 간다는 규칙뿐이다 |
| 번역 앱 | AI | 수많은 문장 쌍에서 번역하는 법을 배웠다 |
| 정해진 시간에 울리는 알람 | 아님 | 시간이 되면 울린다는 규칙이다 |
| 음성 비서 (“오늘 날씨 알려 줘”) | AI | 목소리를 글자로 바꾸고 뜻을 알아듣는다 |
| 스팸 메일 자동 분류 | AI | 스팸 예시를 보고 비슷한 메일을 찾아낸다 |
| 사람이 오면 열리는 자동문 | 아님 | 센서가 감지하면 연다는 규칙이다. 센서가 있다고 AI는 아니다 |
| 사진 앱의 “강아지 사진” 모아 보기 | AI | 사진 속 강아지 모양을 배워 알아본다 |

### 스테이지 2. AI 타임머신
- 순서 맞추기 5장: 1950 튜링 “기계가 생각할 수 있을까?” · 1956 ‘인공지능’이라는 이름 탄생(다트머스 회의) · 1997 체스 컴퓨터 딥블루가 세계 챔피언을 이김 · 2016 알파고가 이세돌 9단을 이김 · 2022 ChatGPT 공개
- 이어서 4지선다 3문항: ‘인공지능’이라는 말이 처음 생긴 해(1956) / AI에 대한 기대가 식어 연구가 줄어든 시기(AI 겨울) / 알파고가 이긴 게임(바둑)

### 스테이지 3. 다음 단어를 맞혀라
- 개념 2문항: 생성형 AI의 뜻(새로운 글·그림 등을 만들어 내는 AI) / 포함 관계(인공지능 ⊃ 머신러닝 ⊃ 딥러닝)
- 다음 단어 4문항: 문장 앞부분 + 4개 선택지. 답하면 “AI가 매긴 확률(예시)” 막대 공개. 가장 높은 단어를 고르면 정답.
  - “비가 와서 우산을 ___” 챙겼다 55 / 샀다 25 / 펼쳤다 15 / 먹었다 1
  - “아침에 일어나서 이를 ___” 닦았다 80 / 봤다 8 / 셌다 5 / 심었다 1
  - “도서관에서는 ___ 해야 한다” 조용히 70 / 크게 3 / 빨리 10 / 함께 12
  - “생일 축하 노래를 부르고 케이크의 ___을 껐다” 촛불 85 / 불 10 / 전등 3 / 노래 1
- 마무리 1문항: 항상 1위 단어만 고르면? → 늘 비슷하고 무난한 글이 된다
- 확률 숫자는 설명용 예시임을 화면에 표시한다.

### 스테이지 4. AI 거짓말 탐지기
- 가상의 AI 답변(세 문장)에서 틀린 문장 고르기 3문항
  - 세종대왕: 훈민정음 1443년 창제·1446년 반포 / 조선 4대 왕 / **거북선을 직접 설계** (이순신 장군 시대)
  - 물: 1기압에서 100℃에 끓는다 / 0℃에서 얼기 시작 / **산소 2개와 수소 1개** (수소 2, 산소 1)
  - 달: 약 한 달에 한 번 지구를 돈다 / 공기가 거의 없다 / **스스로 빛을 낸다** (햇빛 반사)
- 출처 1문항: AI가 알려 준 논문 출처(가상) → 바로 믿기 / **실제로 있는지 검색해 확인**
- 용어 1문항: 그럴듯하지만 틀린 내용을 말하는 현상 → 할루시네이션(환각)
